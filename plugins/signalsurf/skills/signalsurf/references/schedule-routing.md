# Schedule routing

Both schedulers run the same logical SignalSurf Agent; they are not different roles.

- Prefer a SignalSurf Schedule for shared Project or team automation whose inputs, result, and permissions belong in SignalSurf.
- Prefer the host's scheduler for personal reminders, local files, or cross-service routines owned by that host.
- Do not invent Schedule-specific memory, activity, Thread links, action policies, or deletion behavior. Scheduled work uses ordinary permissions, operation records, Project/Thread persistence, and memory behavior.
