# Signalsurf Writing

Read the [shared operating contract](../signalsurf/references/operating-contract.md) before accessing Signalsurf resources unless already loaded. Writing guidance grants no data access, paid research, send or publication authority. Standalone prose with supplied context needs no Workspace or Project mutation.

1. Resolve the requested operation: write new copy, review without editing, or rewrite the supplied text. Respect selected passages and exact-copy requests. Use known purpose, audience, channel, language and context; ask only for a missing choice that materially changes the result.
2. Read [core writing](references/core.md) and [author voice](references/voice.md). Facts come from authorized context and supplied evidence. Voice samples are a separate input.
3. Load only the matching reference below. Chinese copy also uses [Chinese calibration](references/chinese.md). Review and rewrite use [editing](references/review.md). Do not apply a post formula to a comment or a cold-email formula to an existing conversation.
4. Write or edit against those rules. Check supported claims, voice, intent, quotes, selection boundaries and actual platform constraints. Return the requested deliverable; private checks are not part of sendable copy. For review, report concrete findings and stop without rewriting.
5. Save or send only when requested through the existing Content, Campaigns, Listening or Inbox Skill. For Content, apply this guidance before writing shared/per-account bodies, then save through `content_manage`; preserve authored account variants. Listening drafts use `listening_reply` action `draft`; instructions belong in its supported fields, never invented schema fields. Drafting does not authorize sending.
