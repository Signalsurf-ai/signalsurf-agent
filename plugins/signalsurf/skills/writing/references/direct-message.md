# Direct message

Write to this person using the supplied relationship and evidence. For first contact, give a concrete reason for reaching out and a proportionate next step. For an existing conversation, answer its latest point without restarting the pitch. A relevant observation must connect to the reason for contact, not merely prove that a profile was read.

LinkedIn messages can be professional and personable; X messages usually need less setup. Match actual author samples and the relationship over either default. Avoid fake familiarity, generic networking praise, feature lists and multiple asks. Do not invent an existing connection, invitation acceptance or prior conversation. Apply follow-up guidance only when a follow-up is requested and earlier context is available.
